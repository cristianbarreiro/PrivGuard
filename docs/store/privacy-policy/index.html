English Version (en-us)

Core Privacy Commitment: PrivGuard is an offline, local-first privacy utility for Windows 10 and 11. PrivGuard does not transmit data over the network, does not collect personal identity information, does not record audio or video streams, and contains zero third-party analytics or telemetry SDKs.

1. Audio & Video Processing Boundaries

  • Zero Audio Recording: PrivGuard interacts solely with Windows Core Audio APIs (IAudioEndpointVolume via WASAPI) to query and toggle the master software mute switch on active recording endpoints. PrivGuard never reads audio buffer samples, never listens, and never records conversations.
  • Software Mute Limitations: The muting applied by PrivGuard is software-level at the Windows audio endpoint. Specific hardware drivers or applications running in exclusive stream mode may bypass Windows endpoint muting. PrivGuard is not a physical hardware disconnect switch.
  • Zero Camera Frame Access: PrivGuard Store Edition does not access, intercept, or render camera video frames. For camera privacy, the application provides a direct shortcut to Windows native Camera Privacy Settings (ms-settings:privacy-webcam).
  • Not Antivirus or Anti-Spyware: PrivGuard is a user-controlled privacy management tool, not an antivirus, anti-spyware, or threat detection engine.

2. Network Transmission & Telemetry Audit

  • Zero Network Transmission: PrivGuard initiates zero HTTP/HTTPS requests, opens zero network sockets, and declares zero network capabilities in its package manifest (internetClient is absent).
  • Zero Remote Telemetry: PrivGuard does not integrate analytics frameworks, cloud crash collectors (such as Sentry or AppCenter), or tracking pixels.
  • Distribution: Updates are distributed exclusively through the Microsoft Store client. PrivGuard performs no independent remote update queries.

4. Data Retention & Uninstallation Guide

Because PrivGuard Store Edition stores its files in %LOCALAPPDATA%\PrivGuard\Store\ rather than the Windows-managed package family folder, the standard Windows MSIX uninstaller may not automatically delete this custom directory.

To completely remove all local data:

  1. Open PrivGuard and ensure the microphone is unmuted if you wish to restore default Windows audio behavior.
  2. Right-click the PrivGuard System Tray icon and select Exit to close the recovery journal cleanly.
  3. Uninstall PrivGuard via Windows Settings (Settings > Apps > Installed apps > PrivGuard > Uninstall).
  4. Press Win + R, paste %LOCALAPPDATA%\PrivGuard\Store, press Enter, and delete the folder.

Versión en Español (es-es)

Compromiso Fundamental de Privacidad: PrivGuard es una utilidad de escritorio local y desconectada para Windows 10 y 11. PrivGuard no transmite datos por la red, no recopila datos de identidad personal, no graba secuencias de audio ni de video, y no integra herramientas analíticas o de telemetría de terceros.

1. Alcance y Límites de Procesamiento de Audio y Video

  • Cero Grabación de Audio: PrivGuard interactúa exclusivamente con la API de Windows Core Audio (IAudioEndpointVolume mediante WASAPI) para consultar y conmutar el silenciado maestro por software de los dispositivos de entrada. Jamás lee muestras de audio ni graba conversaciones.
  • Límites del Silenciado por Software: El silenciado opera a nivel de software en Windows. Ciertos controladores especializados o aplicaciones en modo exclusivo pueden eludir este silenciado. PrivGuard no es un interruptor físico de corte de hardware.
  • Cero Acceso a la Cámara: PrivGuard Store Edition no accede, intercepta ni procesa imágenes de la cámara. Proporciona un enlace directo a la configuración nativa de Windows (ms-settings:privacy-webcam).
  • No es Antivirus ni Anti-Spyware: PrivGuard es una herramienta de gestión de privacidad, no un antivirus ni un motor de detección de amenazas.

2. Auditoría de Red y Telemetría

  • Cero Transmisión de Red: No efectúa peticiones HTTP/HTTPS, no abre sockets y su manifiesto de paquete carece de capacidades de red (internetClient no está presente).
  • Cero Telemetría Remota: No incluye SDKs de análisis, servicios de reporte de caídas en la nube ni módulos publicitarios.
  • Distribución: Las actualizaciones se gestionan exclusivamente a través del cliente de Microsoft Store sin comprobaciones remotas independientes.

4. Retención y Desinstalación Limpia

Al utilizar %LOCALAPPDATA%\PrivGuard\Store\ y no la carpeta gestionada por el sandbox de Windows, el desinstalador de MSIX podría no borrar automáticamente esta carpeta personalizada.

Pasos para la eliminación total de datos:

  1. Abre PrivGuard y asegúrate de que el micrófono esté desilenciado si deseas dejar el audio en su estado habitual.
  2. Haz clic derecho en el icono de PrivGuard en la bandeja del sistema y selecciona Salir para cerrar el diario de recuperación.
  3. Desinstala la app desde Configuración de Windows (Configuración > Aplicaciones > Aplicaciones instaladas > PrivGuard > Desinstalar).
  4. Pulsa Win + R, introduce %LOCALAPPDATA%\PrivGuard\Store, pulsa Enter y elimina la carpeta.
